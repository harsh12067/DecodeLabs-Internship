This repository contains all my projects completed during the DecodeLabs Internship.

- **[Project 1 - AetherFlow Landing Page](./aetherflow-landing-page/):** A responsive SaaS landing page demonstrating HTML5, CSS3, and Vanilla JavaScript fundamentals.

## 🚀 Projects Overview

### 1. AetherFlow Landing Page (Project 1)
A premium, framework-free frontend build showcasing:
- Sticky header, responsive navigation, and hamburger menu.
- Glassmorphic card design and modular CSS variable schemes.
- Active navigation scroll highlighting via `IntersectionObserver`.
- FAQ accordions and services modal popup boxes.
- Client-side form validation with real-time regex parameters.
